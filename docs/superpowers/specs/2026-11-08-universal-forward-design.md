# Universal Forward Plugin for Mattermost: Design

تاریخ: 2026-11-08
هدف سرور: Mattermost Enterprise 10.5.2 (self-hosted)

## هدف
فوروارد پیام از هر جایی که پیام نمایش داده می‌شود (کانال، نتایج جستجو، Saved، Mentions، ترد در RHS)، نه فقط از داخل همان چت.

## محدوده (Scope)
- فقط پلاگین webapp. بخش سرور ندارد (YAGNI). همه کارها با API استاندارد و با دسترسی خود کاربر انجام می‌شود، پس مشکل authorize برای ارسال پیدا نمی‌شود.
- خارج از محدوده: بخش سرور، چک دقیق دسترسی همه اعضای کانال مقصد، کپی فایل‌های پیوست، فوروارد چندپیامی.

## رفتار

### 1. گزینه در منو
با `registerPostDropdownMenuAction` یک آیتم «Forward to…» به منوی «...» هر پیام اضافه می‌شود.
ریسک: باید در ابتدای پیاده‌سازی روی 10.5.2 تأیید شود که منوی جستجو، Saved و Mentions آیتم پلاگین را نشان می‌دهد. اگر نشان نداد، راه جایگزین طراحی می‌شود.

### 2. انتخاب مقصد
Modal با جستجوی کانال‌ها و کاربران (برای DM)، فیلد توضیح اختیاری و دکمه Send. برای DM در صورت نبودن کانال direct، با `POST /channels/direct` ساخته می‌شود.

### 3. تصمیم لینک یا کپی
- مقصد DM: اگر آن کاربر عضو کانال مبدأ است، permalink. وگرنه کپی.
- مقصد کانال: اگر کانال مبدأ عمومی و هم‌تیم با مقصد است، permalink. اگر مبدأ خصوصی، DM یا GM است، کپی.
- در حالت کپی، قبل از ارسال هشدار در modal نشان داده می‌شود.

### 4. قالب کپی
```
> متن پیام
فوروارد از @کاربر در ~کانال، تاریخ
```
فایل‌های پیوست کپی نمی‌شوند و فقط نامشان در متن می‌آید، چون API اجازه نمی‌دهد فایل یک پیام به پست دیگر وصل شود.

### 5. خطاها
اگر ارسال مجوز نداشت یا سرور خطا داد، همان پیام خطا در modal نشان داده می‌شود و modal بسته نمی‌شود.

## ساختار کد
- `decideMode(source, destination, membership)`: تابع خالص، خروجی `permalink | copy`.
- `buildCopyMessage(post, author, channel)`: تابع خالص.
- `ForwardModal`: UI و جستجوی مقصد.
- `index`: ثبت آیتم منو و root component.
- `api`: لایه نازک روی API سرور (جستجوی کانال و کاربر، عضویت، ساخت پست و کانال direct).

## تست
- Unit test برای `decideMode` و `buildCopyMessage` (تمام شاخه‌ها).
- تست دستی روی سرور 10.5.2: کانال، جستجو، Saved، Mentions، RHS، و هر دو حالت لینک و کپی.
